## E. Bugs found and fixed

1. Windows-only paths and import-time HGB model loading prevented API startup on this machine. Startup now works without a trained model.
2. Legacy API exposed reference arc IDs and reference geometries despite documentation claiming isolation. New endpoints return permitted inputs, predictions and aggregate metrics only; references are read only after inference returns.
3. Wildcard credentialed CORS was replaced by explicit frontend origins. Backend URL is configurable and persisted in the browser; file:// origin is not supported.
4. Legacy decoder mixed feature extraction, arbitrary classifier inference and evaluation, allowed finite disconnected/reverse-junction jumps and failed on empty middle groups. Production decoding validates grouped scores and directed graph IDs, fails on missing groups, and splits explicitly when a continuous directed run cannot be sustained.
5. Historical continuity metric in training code counts repeated arc IDs, not directed adjacency. Historical scripts/results were retained, but that metric is not used or advertised by the new app.
6. Authoritative features differ from the historical pipeline (15 versus 10, five candidates versus 10–15). The new app refuses to substitute that pipeline.
7. Supplied scaler order differs from Parquet bearing-column order. Manifest requires explicit preprocessing order; adapter restores canonical model order after transformation. No refitting occurs.
8. Native browser fetch required a global receiver; binding it correctly fixed an issue that mocked request tests initially missed. A regression test now covers that receiver.
9. Stale responses and polled jobs are guarded against trip/connection changes. Metrics/results clear before a new selection, network errors show retry guidance, and browser disconnects do not cancel jobs.
10. Shell-dependent Python selection revealed a crashing Anaconda/PyArrow environment. Verification was rerun in a virtual environment using the known-working framework Python; this environment limitation is documented.
